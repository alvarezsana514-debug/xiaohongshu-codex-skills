# 小红书 AI 漫剧图片文案与生图

用参考图确定选题、语言风格和排版容量，用知识库支撑新文案，再逐页生成对应图片。处理全部图组，不跨组混用。

**REQUIRED SUB-SKILL:** Use gpt-image-2-http for image generation.

## 默认设置

- 知识库：优先使用用户指定路径；未指定时使用当前工作区中的知识库。无法确定知识库位置时先询问用户。
- 项目结构：`参考图/<图组>/<数字文件>`。
- 只生成图片文案和图片，不生成笔记标题、正文或额外版本。
- 详细命令见 [workflow.md](references/workflow.md)，提示模板见 [prompts.md](references/prompts.md)。

## 流程

1. **扫描**：运行 `project_scan.py`，按数字顺序处理全部可读图片；记录图组、页数、顺序和异常后自动继续。
2. **提取**：逐图提取标题与正文，视觉标识另列。保留已有提取文件，新建 `工作文件/参考图文案提取-YYYY-MM-DD-HHmmss.md` 后自动继续。
3. **更新索引**：把知识库增量索引写入项目的 `工作文件/知识库索引.json`，按图组检索并回查原文。
4. **重新仿写**：每次调用都基于本次提取结果和最新索引重新生成逐页文案；学习参考图的语言风格、表达节奏和排版容量，优先保证内容质量、通顺度和可读性，不强制等字。
5. **批量质检**：检查页数、原创度、事实依据、语言通顺、排版适配和公众平台风险，只返修失败页。写入 `工作文件/仿写图片文案.md` 与 `工作文件/质检结果.md` 后自动继续。
6. **检查生图密钥**：仅在前五步完成后检查 `GLOBALAI_API_KEY`。密钥缺失不影响扫描、提取、检索、仿写和质检，只暂停生图。
7. **生图与检查**：逐页提交“当前参考图＋当前最终文案”给 `gpt-image-2-http`，输出 `1152x1536`、high、PNG 到 `最终图片/<图组>/<页码>.png`。运行 `image_checks.py` 并写入 `工作文件/成图检查结果.md`。

## 必要边界

- 扫描、提取和文案质检完成后自动继续，不设置用户确认门；仅在输入无法读取、目标冲突或外部调用失败时暂停。
- 固定顺序：扫描 → 新建提取文件 → 更新索引 → 重新仿写 → 批量质检 → 检查生图密钥 → 生图。必须严格按顺序执行，不得跳步、提前检查后续阶段或因后续阻塞省略前序阶段。
- 后续阶段的阻塞只暂停该阶段；凡是不依赖该阻塞的前序阶段都必须先完成并检查产物。
- 已有同名结果不覆盖；先报告并获得确认。
- 资料事实必须回查。知识库不足时，可用 AI补充通用方法、经验建议和解释性内容，并在质检中标记；不得补写事实数字、课程权益、平台政策、人物经历、收益或效果承诺。
- 默认禁用收益、报价、GMV、分成、曝光量、市场规模、薪资、商单数量及确定性结果承诺。
- 保留参考图的风格和营销节奏，但不得照搬句子；具体文字重合率不得高于 20%。
- 单页生图失败时停止当前图组并报告，不自动换模型或无限重试。
