# 提示模板

## 逐图提取

```text
提取 {{group_name}}/{{image_filename}}（{{i}}/{{N}}）的标题和正文。
逐图记录，不合并、不概括、不补写；模糊文字标“待确认”。Logo、水印、页码和装饰字另列为视觉元素。
```

## 知识库仿写

```text
参考页：{{reference_copy}}
知识依据：{{knowledge_evidence}}
允许的AI补充：{{ai_supplement}}

为当前页写一版新的 AI视频／漫剧图片文案：
- 学习参考页的选题角度、语言风格、语气、节奏和排版容量，不照搬句子。
- 优先保证原创度、文案质量、语言通顺和信息价值；长度适合原版式即可，不强制等字。
- 事实来自知识库。AI补充只用于通用方法、经验建议和解释，不补写事实数字、课程权益、平台政策、人物经历、收益或效果承诺。
- 不使用收益、报价、GMV、分成、曝光量、市场规模、薪资、商单数量和确定性承诺。
- 只输出当前页标题与正文。
```

## 批量质检

```text
批量检查全部候选页：
1. 页数和顺序正确；每页容量适合对应参考图。
2. 具体文字重合率不高于20%，无长句照搬。
3. 文案符合参考页语言风格，表达自然、通顺、无空话和无意义凑字。
4. 资料事实可回查；AI补充已标记且未越界。
5. 无公众平台高风险信息。

只返修失败页。质检结果简要记录参考文件、AI补充、原创度、通顺度和风险结果。
```

## 逐页生图

```text
图组 {{group_name}}，第 {{i}}/{{N}} 页。
最终文案：{{confirmed_copy}}

参考当前图片的配色、视觉层级、字体感觉和排版，生成一张3:4竖版小红书图片。只使用当前页文案，不跨页拼接；文字清晰，画面干净，核心信息不得改变，不加入新事实。
```
