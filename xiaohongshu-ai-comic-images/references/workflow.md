# 执行速查

## 文件

```text
项目/
├── 参考图/<图组>/<页码>.<png|jpg|jpeg|webp>
├── 工作文件/
│   ├── 参考图文案提取-YYYY-MM-DD-HHmmss.md
│   ├── 知识库索引.json
│   ├── 仿写图片文案.md
│   ├── 质检结果.md
│   └── 成图检查结果.md
└── 最终图片/<图组>/<页码>.png
```

## 命令

1. 扫描：`project_scan.py <项目路径>`
2. 索引：`knowledge_index.py build <知识库> --index <项目>/工作文件/知识库索引.json`
3. 检索：`knowledge_index.py search <查询> --index <索引> --top-k 8`
4. 文案机械检查：`content_checks.py <参考文案> <候选文案>`
5. 成图检查：`image_checks.py <项目路径>`

## 自动推进

- 图组扫描、参考文案提取和最终文案质检均无需用户确认，完成后自动继续。
- 保留已有提取文件；每次调用新建 `参考图文案提取-YYYY-MM-DD-HHmmss.md`，不得覆盖历史版本。
- 只有输入无法读取、目标文件冲突或外部调用失败时才暂停。
- 严格顺序：扫描 → 新建提取文件 → 更新索引 → 重新仿写 → 批量质检 → 检查生图密钥 → 生图。
- 不得提前检查后续阶段。后续阶段的阻塞只暂停该阶段，不能省略此前可独立完成的工作。
- `GLOBALAI_API_KEY` 仅在生图前检查；密钥缺失不影响扫描、提取、检索、仿写和质检。

## 仿写与质检

- 每个图组单独检索；同等相关性时优先 `03_项目规范/`，再用 `02_资料库/`。
- 参考图提供页面功能、语言风格、节奏和大致排版容量；知识库提供事实与选题。
- 新文案必须原创、自然、通顺，信息完整。长度只需适合原排版，不做逐字对齐。
- `content_checks.py` 批量筛查重合率和风险词；字数、标题与结构数据仅供排版参考，不作为失败条件。
- 模型复查语言是否像参考赛道、是否顺口、是否有空话、是否有知识依据。只修改失败页。
- 质检文件简要列出每页参考文件、AI补充和风险结果，不写冗长推理。

## 生图

最终文案通过质检后，阅读 `gpt-image-2-http` Skill，并固定调用其 `scripts/edit_image.py`：

```text
--image <当前参考图>
--model gpt-image-2
--size 1152x1536
--quality high
--output-format png
--n 1
--output-file <项目>/最终图片/<图组>/<页码>.png
```

每次只使用当前页参考图和当前页文案。目标文件已存在或格式不受支持时停止并询问，不覆盖、不降级为纯文生图。
